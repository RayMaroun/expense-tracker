# Migration: moment → date-fns, float dollars → integer cents

## Done
1. `packages/shared`: date helpers on date-fns; money helpers on integer cents with `dollarsToCents` / `formatCents` at the edges.
2. `packages/api`: routes on date-fns; reports computed in `America/Los_Angeles` with `@date-fns/tz`; data seeded in cents.
3. `packages/web`: page formats dates with date-fns and money with `formatCents`.
4. Tests: `packages/shared/test`, `packages/api/test` (Node's built-in runner).
5. `moment` and `moment-timezone` removed from every `package.json`.

## Out of scope
- `packages/legacy-clients` is retired and excluded from the agent's view; it is not migrated.
- `packages/web/dist` is build output and is regenerated by `npm run build`.
